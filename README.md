# For Khushi, My Bubu — Birthday Website

A mobile-first, static birthday website built with plain HTML, CSS, and JavaScript. No framework, backend, account, build step, external font, or dependency is required.

## Run locally on your Mac

1. Open this folder in VS Code.
2. Open `index.html` in your browser, or use the VS Code **Live Server** extension if you already have it.
3. The first screen opens the birthday surprise. Test the reveal button, the teasing interaction, navigation links, photo slots, and the replay button.

## Original photos included

The `assets/` folder contains the seventeen original photos supplied for this website (`photo-01.png` through `photo-17.png`) and the proposal-day photo (`proposal-day.png`). The proposal photo is shown in the story timeline. All originals are copied without retouching, recolouring, or AI alteration. Images are displayed with `object-fit: contain` so the whole image remains visible.

The 17 memories are split across five personal chapters instead of one long gallery: tiny details, soft/funny moments, eye contact, little adventures, and caring for each other. Captions are based on the personal descriptions provided alongside each upload.

## Deploy with GitHub Pages

1. Create a new **public** GitHub repository (for example `bubu-birthday`) and upload the contents of this folder to its root. If you'd prefer private, check the GitHub Pages availability/settings for your account first.
2. In the repository, open **Settings → Pages**.
3. Under the build/deployment source, select **Deploy from a branch**, choose `main` and `/(root)`, then save.
4. Wait for the deployment status to finish and open the URL shown on the Pages settings screen. Check the phone layout and photos in that exact live URL before sending it to her.

Do not put private notes, phone numbers, addresses, passwords, or anything that should remain secret in a public repository. The birthday site itself contains no analytics, form submissions, trackers, or third-party embeds.
